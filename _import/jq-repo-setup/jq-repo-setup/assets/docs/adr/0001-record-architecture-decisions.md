# 0001. Record architecture decisions

- **Status**: Accepted
- **Date**: <YYYY-MM-DD>

## Context

Decisions about architecture, dependencies, security and scope are easy to forget and
hard to reverse. New contributors (people and coding agents) need to know why things are
the way they are.

## Decision

We will record every hard-to-reverse decision as an ADR in `docs/adr/`, in the same pull
request as the change. Accepted ADRs are superseded, never rewritten.

## Consequences

Reviewers can ask "where is the ADR?" for structural changes. The index in
`docs/adr/README.md` must be kept current.
