# yt-notes

A Claude skill that turns YouTube videos into study notes, saved to `~/video-notes/`.

Requires [yt-dlp](https://github.com/yt-dlp/yt-dlp). Checks GitHub once a day for a newer
release of this skill and prints a one-line notice.
